우리 집 환경에서는 뭐가 달라질까

집 네트워크 구성 (2026-11-26 기준)
  • 공유기: RT-AX58U (192.168.50.1) · NAS DS920+ (192.168.50.90, 1GbE) · 테일스케일 UDP 41641 포트포워딩으로 5080 PC와 직접 연결
  • 5080 PC는 공유기 바깥 서브넷(스위칭허브 직결) — 선 옮기기는 어렵다고 결정됨
  • 무선 기기: 아이폰 13 Pro Max (Wi-Fi 6) · 아이패드 Pro M4 (Wi-Fi 6E, 6GHz 가능) · 그램 노트북
  • 미니PC: GMKtec M8 · FIREBAT F1 (둘 다 2.5G LAN 탑재)
  • 나스에서 돌아가는 것: Immich · Paperless-ngx · JDownloader · 테일스케일

✅ 바꾸면 좋아지는 것

  • Wi-Fi 7 — 무선 속도·지연·다중 접속 개선 (MLO, 4096-QAM)
  • 2.5GbE 포트 — M8·F1의 2.5G LAN을 제대로 활용 (NAS는 1G라 NAS 전송은 그대로)
  • CPU·RAM 여유 — 1GB RAM + 쿼드코어, 기기 10대 이상 + VPN·QoS에도 안정
  • 6GHz 대역 — BE92U 한정. 아이패드 M4가 6GHz로 붙으면 5GHz 혼잡을 피할 수 있음
  • 보안 업데이트 — 신형은 펌웨어 지원이 한참 남음

❌ 바꿔도 안 바뀌는 것

  • 5080 PC ↔ NAS 속도 — 선/서브넷 문제라 공유기 교체로 안 풀림. 테일스케일 직접 연결은 이미 되어 있음
  • NAS 전송 속도 — DS920+는 1GbE라 공유기가 2.5G·10G여도 NAS와 주고받는 속도는 1G 그대로
  • 인터넷 속도 자체 — 요금제가 그대로면 그대로. 기가 인터넷이면 지금 공유기도 이미 포화 상태

교체할 때 체크리스트

  1. 기존 공유기 설정 백업 — 관리 페이지 → 관리 → 설정 파일 저장. 새 공유기에 그대로 올리면 Wi-Fi 이름·비밀번호·포트포워딩이 그대로 옮겨져요.
  2. 포트포워딩 다시 만들기 — UDP 41641 → 192.168.50.90 (테일스케일 직접 연결용). 이거 안 하면 5080 PC ↔ NAS가 중계(DERP)로 느려져요.
  3. Wi-Fi 이름·비밀번호 그대로 쓰기 — 기기들을 일일이 다시 연결할 필요가 없어요.
  4. AX58U는 버리지 말 것 — AiMesh 노드로 재활용하면 집 구석 음영 지역 커버가 돼요.
  5. 새 공유기 펌웨어 최신으로 업데이트 후 사용하기.
  6. 테일스케일 IP는 그대로 — 공유기 교체와 무관하게 NAS 100.115.240.90, 5080 PC 100.75.164.64는 그대로예요.
